# Cerberus Vault

Gerenciador de senhas local com criptografia AES-256-GCM e PBKDF2.

## Extensão beta para Chrome e Edge

A pasta [`extension`](extension/) contém uma extensão Manifest V3 para instalação manual. Ela importa o backup JSON criado pelo aplicativo e preenche credenciais somente após clique explícito e validação exata do domínio.

Consulte as [instruções de instalação](extension/README.md).
